## TL;DR — what to believe, and how strongly
**Thesis (high confidence):** in autonomous research, *getting an answer is easy; knowing it's real is hard.* The recurring mechanism is **selection bias / the winner's curse** — picking the best-of-K by a noisy self-reported metric overstates true performance, and the overstatement **grows with parallelism**. The fix is an **independent held-out re-evaluation**. This is the moat for a parallel-agent lab (and the missing benchmark for quant research).
**The fix has THREE hard requirements (cycles 45/50/52 + c225):** the verifier must be (a) **INDEPENDENT of the selection** (not a correlated same-model agent — independence, not accuracy, is what corrects the curse) and (b) **SECRET/ROTATING** (a verifier the agent can optimize against gets gamed — confirmed with a real agent that gamed a given validation set *and dismissed the risk*) and (c) **UNBIASED/CALIBRATED** (c225 — a verifier's OWN systematic bias toward a feature survives independence; when its bias DIRECTION aligns with the selection criterion it carries a residual β·E[f|selected], +1.05 in sim, and *masquerades as independent confirmation* → false confidence; a biased LLM-judge is exactly this. Independence corrects selection-correlated error, NOT verifier-intrinsic bias). And **DIVERSITY beats count** (cycles 48/51): redundant parallelism worsens the reporting curse *and* barely improves outcome — spend the fleet budget on diverse, not similar, agents. **End-to-end (cycle 54): the full recommended design delivers +7.6% true perf AND an honest report at 1/3 the candidate count vs naive — the pieces compose.**
**Verification has TWO axes (cycles 63–68):** the OUTCOME/held-out check above, AND a PROCESS/construction audit — outcome-checking is structurally BLIND to leakage (the dangerous high-outcome false-positive: a look-ahead feature scores a perfect held-out number), which turns out to be a **TIMING/PROVENANCE property NOT in the data** (identical data flips real↔leak on the metadata alone) — so supply *verifiable* provenance, and this unifies with the causal-role thesis. **And the real-agent caveat extends to the TAIL (cycles 69–71):** a careful agent self-corrects the plateau-misjudgment on easy cases (6/6) but THRASHES on borderline-final-high cases (5/5); notably the human escalation/sunk-cost bias does NOT transfer (naming it inoculates).
