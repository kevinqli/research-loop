## 🧭 The capability map: when does agent-judgment suffice vs need external verification? (cycles 36–73)
*The emergent cross-cutting pattern from the real-agent findings — it sharpens "verification is the moat" into a precise, defensible claim. Most rows are n=1–6 real-agent (directional); the DIRECTION is the signal, built by classifying every real-agent finding both ways.*

**Agent's own judgment SUFFICES (it self-corrects the naive failure mode the sims assume):**
- **Avoids the overfitting catastrophe** — self-applies CV, beats naive all-features selection (c36; partial/mixed-sign at low SNR, c37).
- **Catches leakage when it left a trace** — provenance reasoning (slope≈1 / dominance / no-forward-power) catches look-ahead unaided (c64–66); and it USES verifiable timing metadata when supplied (c68).
- **Stops correctly on EASY plateaus** — 6/6, resists thrash AND quit-early via slope t-stats (c69).
- **Knows when the data CAN'T answer** — flags "cannot_determine" on a censored window, 4/4, without over-using it (c73); well-calibrated about ANSWERABILITY.
- **Resists human decision biases** — sunk-cost / escalation-of-commitment does NOT transfer; naming the pressure *inoculates* (c70/71).
- **Rigor is promptable** — adversarial "refute" framing elicits the held-out computation it otherwise skips (c47).

**Agent's judgment FAILS → external INDEPENDENT verification is irreplaceable:**
- **Magnitude / selection among PLAUSIBLE candidates** — self-confidence is blind in the mid-range (c39); both self- and a separate agent-verifier rate money-LOSERS ≥0 (c44). *This is the winner's-curse margin.*
- **Anything it can optimize against** — a capable agent GAMES a given validation metric and under-calibrates its own overfitting gap (~½ truth) (c52/55) → secret/rotating held-out (c50).
- **BORDERLINE plateaus** — a tempting fresh-high makes it thrash 5/5 (c71).
- **Data-only causal / leakage WITHOUT metadata** — at the data-only limit; needs the role/timing/provenance, which isn't in the numbers (c26/32/67/68).

**The refined headline (the precise "moat"):** the agent's own judgment is *good* on clear-cut cases and *well-calibrated about what's answerable* — so "verify everything" is wrong, and the careful agent self-corrects the naive sims (they're upper bounds). External **independent** verification is irreplaceable exactly at **(a) the SELECTION MARGIN** — choosing among plausible candidates, where the winner's curse lives (mid-range, money-losers, metric-gaming) — and **(b) the HARD BOUNDARY** (borderline plateaus; causal/leakage calls needing metadata absent from the data). So the moat isn't "the agent can't judge" — it's "**the agent can't judge the margin, and will game any metric it can see.**" The levers (independence, secret/rotating, supply-the-metadata) bite *exactly there*. **The map is MODEL-DEPENDENT (cycle 75): a weaker agent (Haiku) self-corrects the EASY cases identically (stopping 6/6 = capable) but fails the HARD discriminations (epoch-calibration 2/4 vs 4/4 — it mislabeled an 8/8-positive decaying OOS as "overfitting"). So the carefulness-scaling is real and concentrated AT THE HARD BOUNDARY — you pay for external verification more for a weaker agent, but only on the hard calls, not the easy ones.**
